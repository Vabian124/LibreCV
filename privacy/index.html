Privacy

LibreCV does not ask for an account. The CV or motivation letter you write stays in this browser. This site does not show ads.

What stays on this computer

  • The open document, and any copies you save, stay in this browser. Reset clears the open document and every saved copy.
  • Download writes a PDF on this computer. LibreCV does not upload that PDF.
  • The AI template is copied on this device. Paste text uses Chrome's on-device model when that browser has it. Another browser warns first. Sorting text into blocks still works without that model.
  • An https address on a photo frame loads that picture in the browser. LibreCV does not store the picture file.

What you can send

  • Feedback is optional. The form loads when you open it. A private note can include the page address, the browser and window size, or the CV or letter text. Each of those is included only if you tick that box.
  • A GitHub issue is public. Leave the CV out of it.
  • If you paste the template into your own AI, that request goes to the service you chose. LibreCV does not send the text.

The code

The project's own code is CC0, as close to the public domain as the law allows. The bundled libraries keep their own licenses.

Open LibreCV

This LibreCV writes a CV or a motivation letter. It is not the LibreCV computer-vision association, and it is not the SimpleCV Python library.
